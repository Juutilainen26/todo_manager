# 일정 관리 (todo_manager)

상시 ON PC가 **서버**, 각 PC의 **클라이언트(exe)** 가 Tailscale로 접속하는 일정 관리 프로그램입니다.

```
[상시 ON PC] 서버_실행.bat  ←── Tailscale ──→  [내 PC들] TodoManager.exe
   (SQLite: data/todo.db)
```

## 1. 서버 (상시 ON PC)
1. Python 3.10+ 설치 (설치 시 "Add python.exe to PATH" 체크)
2. 이 폴더를 서버 PC에 복사(또는 `git clone`)
3. **`서버_실행.bat` 더블클릭** → 최초 1회만 자동으로 패키지를 설치하고 서버가 시작됩니다.
4. 창에 표시되는 `http://100.x.x.x:8765` 가 **클라이언트 접속 주소**입니다.
   - 처음 실행 시 윈도우 방화벽 팝업이 뜨면 **허용**을 눌러주세요.
- 서버 PC를 재부팅했다면 **`서버_실행.bat`를 다시 실행**해야 합니다. (자동 시작은 일부러 넣지 않았습니다.)
- 서버 창을 닫으면 서버도 종료됩니다.
- **백업**: `data\todo.db` 파일 하나만 복사해 두면 됩니다.

## 2. 클라이언트
- 배포판 실행: `TodoManager.exe` 더블클릭 → 처음 한 번만 서버 주소 입력 → **연결 테스트** → 저장.
- 창을 닫아도 트레이에서 계속 실행되며 마감 알림(3일 전/24시간 전)이 옵니다. 완전 종료는 트레이 아이콘 → 종료.
- 설정/캐시 위치: `%APPDATA%\TodoManager`

### exe 만들기 (윈도우)
- 방법 A (로컬): `빌드_클라이언트.bat` → `dist\TodoManager\TodoManager.exe` (폴더째 복사해서 사용)
- 방법 B (GitHub 자동 빌드): `github_build_workflow.yml` 파일을 **`.github/workflows/build.yml`** 로 옮긴 뒤 저장소에 push,
  이어서 `git tag v1.0.0 && git push --tags`
  → Actions가 exe를 빌드해 **Releases**에 `TodoManager-win.zip`으로 올려줍니다. 다른 PC에서는 이 zip만 받아 풀면 끝.
- 개발 실행(exe 없이): `클라이언트_개발실행.bat`

## 3. 사용법
| 종류 | 설명 |
|---|---|
| 오늘 | 오늘 23:59가 마감인 한 번짜리 일정(빠른 추가용) |
| 매일 | 일정마다 초기화 시각 지정 (예: 04:00, 05:00, 00:00) |
| 주간 | 일정마다 초기화 요일+시각 지정 (예: 월 00:00, 화 00:00, 목 00:00) |
| 앞으로 | 마감일이 있거나 없는 한 번짜리 일정 |

- **빠른 추가**: 상단 입력창에 제목 → Enter (종류 선택). 세부 설정은 `＋ 자세히` 또는 더블클릭(수정).
- **완료/미완료**: 왼쪽 동그라미 클릭 (또는 선택 후 Space). 완료한 것을 다시 누르면 미완료로 돌아갑니다.
- **마감 초과**: 완료와 동일하게 "종료" 상태가 되며(회색 ✕, 목록 아래쪽), **더 이상 완료할 수 없습니다.**
  매일/주간 일정은 다음 초기화 시점에 다시 진행 중으로 돌아옵니다.
- **마감 시각**: 매일/주간은 따로 지정하지 않으면 "다음 초기화 시점"이 마감입니다. 원하면 `마감 시각 지정`.
- 한 번짜리 일정은 종료(완료/마감초과) 후 3일이 지나면 목록에서만 숨겨집니다(데이터는 보관).
- 단축키: `Ctrl+N` 입력창, `F5` 새로고침, `Space` 완료 토글, `Enter` 수정, `Delete` 삭제.
- 알림: 마감 **3일 전 / 24시간 전** 두 번 (한 번짜리·주간 일정만, **매일 일정은 제외**). 트레이 메뉴에서 켜고 끄기.

## 4. 동작 원리 (참고)
초기화를 타이머로 실행하지 않고, 조회할 때 "현재 주기 시작 시각"을 계산해 그 이후에 완료했는지로 판단합니다.
그래서 서버가 꺼져 있다 켜져도 상태가 정확하고, 초기화 시점은 일정마다 제각각이어도 됩니다.
시각은 모두 **서버 PC의 시간**을 기준으로 합니다.

## 5. 문제 해결
- 빨간 배너 "서버에 연결할 수 없어요": 서버 PC에서 `서버_실행.bat` 실행 여부, 양쪽 Tailscale 연결, 주소(⚙) 확인
- 포트 변경: `python run_server.py --port 9000` (bat의 마지막 실행 줄 수정)

## 6. 개발
`pip install -r requirements-server.txt -r requirements-client.txt -r requirements-dev.txt` 후 `python -m pytest`
